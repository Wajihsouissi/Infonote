Liquid Charcoal
A glass layer added on top of Charcoal & Signal. Nothing in the existing token set changes — the material only decides which surfaces stop being opaque.
Glass — chrome only
Top-bar clusters, the bottom rail, the AI dock, context and slash menus, tooltips, the multi-select toolbar, modal scrims. Things that float over the work.
Ink — content stays opaque
Note cards, editor wells, kanban cards, the AI transcript. You read and type here for hours; a moving backdrop behind body text is a legibility tax, not a material.
Anatomy — four layers, in the order light meets them
1 · Specular
Light from above-left, bounce below-right. inset 0 1.2px 0 / .44
2 · Refraction

3 · Frosted core
Blur plus saturation, so colour survives. blur 20 · sat 200%
4 · Rim dispersion
Coral into pink — the split uses the two hues you already own.
